# Among Us: Edição da Lenda — V4 Alpha Online

Pacote de trabalho que preserva o HTML original da V3 Alpha em `public/v3-alpha.html` e mantém o menu/servidor online V4 na página inicial.

## Executar
- Requer Node.js 20+
- `npm install`
- `npm start`
- Menu online: `/`
- V3 Alpha original preservada: `/v3`
- Saúde do servidor: `/health`

## Importante
Este pacote é uma base de integração e testes, não uma declaração de que todos os sistemas planejados para V4 já estão completos. O servidor online tem salas públicas/privadas, códigos, limite de 15 participantes, configurações do anfitrião, bots, sincronização básica de movimento, tarefas, sabotagem, reuniões e votação. A V3 está preservada separadamente enquanto os sistemas são integrados e validados em conjunto. Não publique como versão final antes de testar o multiplayer real com dois dispositivos e concluir a integração.
