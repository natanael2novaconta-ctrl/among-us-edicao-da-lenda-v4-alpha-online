# Among Us: Edição da Lenda — V4 Alpha Online (pacote ajustado)

Este pacote preserva os arquivos exportados do site Base44, incluindo o menu original, rotas de lobby, opções Pública/Privada/Criar sala, interface de código de sala, ajuda “Teclas e Botões”, telas e recursos que vieram no ZIP.

## Ajuste realizado
- Pequena ampliação dos controles móveis (joystick e grupo de botões de ação) em telas touch.
- Ajuste de posicionamento usando áreas seguras do dispositivo (safe areas).
- Ajuste para telas móveis horizontais e baixas.
- Mantida a lógica JavaScript exportada, sem reescrever a navegação ou o fluxo de salas.

## Importante
Este é um pacote de arquivos front-end exportados do site publicado no Base44. Não inclui necessariamente o código-fonte original editável nem os serviços/backend do Base44. As funcionalidades online podem depender da aplicação e dos endpoints Base44 originais; hospedar apenas os arquivos em outro serviço não garante que login, salas, códigos ou partidas continuem funcionando.

## Para testar
Abra o site publicado no Base44 para testar o multiplayer existente. Para publicar alterações de volta no Base44, a alteração CSS precisa ser aplicada ao projeto/editor original (ou o pacote precisa ser implantado num ambiente compatível com as dependências e integrações existentes).
